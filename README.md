# 爪破魔塔：工作列篇（試玩版）

掛在 Windows 工作列正上方的小帶子，貓咪會自己往前走、自己打怪、撿裝備。開著做自己的事就好，有空再點開來換裝備、點天賦。

## 下載

到右邊的 **Releases（發行版）** 下載 `qiuqiu-taskbar-windows.zip`，或直接點：
https://github.com/yayaxcharles/qiuqiu-taskbar/releases/latest/download/qiuqiu-taskbar-windows.zip

## 怎麼開

1. 先把整個壓縮檔解壓縮，再雙擊「爪破魔塔工作列篇.exe」。
2. 如果跳出藍色的「Windows 已保護您的電腦」：點「其他資訊」，再按「仍要執行」。這是因為這個小遊戲沒有買數位簽章，不是病毒。

壓縮檔裡的「讀我.txt」有完整的玩法說明。

更多球球的遊戲、貼圖和四格漫畫：https://qiuqiu-universe.pages.dev
